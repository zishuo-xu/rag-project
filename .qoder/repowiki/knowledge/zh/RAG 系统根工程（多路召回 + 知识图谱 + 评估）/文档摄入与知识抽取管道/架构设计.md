模块按数据管线阶段拆分为四个独立文件：
- `loader.py`：按扩展名映射（`.pdf/.txt/.md/.markdown`）选择 LangChain Loader，为每个 Document 注入 `source/file_path/doc_id/chunk_index` 元数据。
- `chunker.py`：提供递归字符分块 (`RecursiveCharacterTextSplitter`) 与语义分块（相邻句 embedding 余弦相似度低于阈值切分），统一入口 `smart_chunk` 根据配置切换策略，并为 chunk 补全 `chunk_id/position`。
- `indexer.py`：`HierarchicalIndexer` 维护两个 Chroma 集合——L1 摘要集合（LLM 对同 doc_id 分块生成摘要后入库）和 L2 明细集合；`hierarchical_search` 先 L1 定位 doc_id 再用 where 过滤做 L2 精排，失败回退全局检索。
- `graph_extractor.py`：`KnowledgeGraphBuilder` 通过 LangChain Prompt+ChatOpenAI 流式抽取三元组，写入 NetworkX 有向图并以 node_link JSON 持久化，提供 N 跳子图、模糊匹配、统计等查询接口，并通过模块级 `_graph_builder` 单例暴露。
依赖方向单向：loader → chunker → indexer/graph_extractor；所有外部模型（Embedding/LLM）均经 `config.get_settings()` 注入，支持本地 HuggingFace 与 OpenAI 双后端。
