- 所有外部服务实例（Embedding、LLM、Chroma）都通过 `config.get_settings()` 动态读取配置，避免硬编码 API key 或 base_url。
- 每个函数/类顶部用三引号写中文 docstring，参数与返回值以 Args/Returns 段落描述，保持统一的 API 文档风格。
- 对 LLM 调用一律包裹 try/except 并用 logger.warning 记录异常，保证抽取或摘要失败时不中断整体流程。
- Document 元数据约定键名：`doc_id`（来源文件名）、`chunk_id`（唯一标识）、`position`（顺序）、`type`（summary/chunk 等），在 loader 与 chunker 中统一注入。
