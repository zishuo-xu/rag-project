本模块为纯 Python 包 `app.evaluation`，由两个职责清晰的子文件组成：
- `dataset.py`：负责评估数据生命周期管理，通过 `create_eval_dataset` / `load_eval_dataset` / `get_questions_and_answers` 在内存 dict 与 `data/eval_dataset.json` 之间序列化样本（含 question、ground_truth、可选 metadata），并提供内置 `SAMPLE_EVAL_DATA` 和 `init_sample_dataset` 用于快速初始化。
- `metrics.py`：不依赖 ragas 包，基于 OpenAI 兼容接口 + 本地 Embedding 模型自实现 Faithfulness、Answer Relevancy、Context Precision、Context Recall 四个指标；通过 `_llm_judge` 统一调用 Judge LLM（DeepSeek），用 `_extract_json` 鲁棒解析 JSON 输出，再用 `_cosine_similarity` 做向量相似度辅助计算。对外暴露 `evaluate_rag`（完整四指标，需 ground_truths）和 `quick_evaluate`（仅关键词重叠的快速模式）两个入口，内部通过延迟导入 `app.generation.chain.RAGChain` 获取回答与检索来源，避免启动期循环依赖。
- 顶层 `__init__.py` 仅声明包用途，无导出符号，外部按子模块直接 import。
- 评估产物以固定结构写入 `data/eval_report.json`（包含 metrics 汇总与 details 明细），作为持久化报告。
