- 所有面向外部的评估函数采用 try/except 包裹 LLM 调用，失败时返回保守默认值（如 0.5 或 0.0），保证单条样本异常不影响整体评估流程。
- LLM 输出统一经 `_extract_json` 解析，先尝试正则提取最外层 `{...}`，再修复尾部多余逗号，最后回退到只取 score 字段，确保鲁棒性。
- Prompt 模板使用 f-string 拼接，并以“严格JSON”格式约束输出，要求包含 score 等结构化字段，便于后续数值化聚合。
- 日志记录通过 `logging.getLogger(__name__)` 实例化，关键路径（数据集保存/加载、评估开始/完成、异常）均输出中文信息。
- 对可选参数（如 save_path、path、ground_truths）采用 `Optional[...] = None` 并在函数体中 fallback 到默认常量或空结构，保持调用方零侵入。
