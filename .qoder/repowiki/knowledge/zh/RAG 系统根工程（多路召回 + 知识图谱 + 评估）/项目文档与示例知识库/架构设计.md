本模块为纯静态资源目录，不含可执行代码，按用途分为两层：
- `docs/`：面向开发者与使用者的文档，包含 `api.md`（FastAPI 端点规范、SSE 流式响应格式、错误码约定）、`architecture.md`（系统整体设计）和 `interview_guide.md`（RAG 相关面试题）。
- `data/sample_docs/`：10 篇主题各异的中文 Markdown 技术笔记（计算机网络、数据库索引、Docker/K8s、LLM、微服务、Python 性能、RAG、Redis、系统设计、Web 安全），作为 RAG 管道分块、向量化与 BM25 索引的输入样本；文件名即 `doc_id`，被 `POST /api/documents/upload` 直接消费。
依赖方向单向：上层应用通过 HTTP 读取这些文件，本模块不反向依赖任何 Python 包。
