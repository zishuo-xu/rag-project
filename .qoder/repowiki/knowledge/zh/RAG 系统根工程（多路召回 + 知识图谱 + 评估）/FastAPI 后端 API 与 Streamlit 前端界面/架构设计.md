模块由两个并列子包组成，职责清晰分离：
- `app/api/`：基于 FastAPI + Pydantic 的 HTTP 服务入口。`schemas.py` 集中定义所有请求/响应模型（ChatRequest/Response、DocumentInfo、EvalReport、HealthResponse 等），`routes.py` 通过一个 `APIRouter()` 注册 `/api/chat`、`/api/documents/*`、`/api/retrieval/compare`、`/api/traces*`、`/api/evaluate`、`/api/graph/*`、`/api/health` 等端点；RAGChain 实例以全局变量 `_rag_chain` 懒加载并通过 `get_rag_chain()/set_rag_chain()` 注入，避免在路由中重复构造。
- `frontend/app.py`：独立 Streamlit 应用，硬编码 `API_BASE_URL=http://localhost:8000`，通过 `requests` 调用后端 REST 接口，使用 SSE 流式解析 `/api/chat` 的 token 事件实现打字机效果，并以 HTML/CSS 内联方式渲染管道流程图、向量条形图、BM25 词项标签和 Trace 瀑布图等可视化面板。
依赖方向单向：frontend → api → app.ingestion / app.retrieval / app.generation / app.observability / app.evaluation，本模块不反向依赖这些业务子包。
