- 路由函数统一通过 `get_rag_chain()` 获取全局 RAGChain 单例，而非在每次请求中重新构造。
- HTTP 异常采用 `raise HTTPException(status_code=..., detail=...)` 返回结构化错误信息，并在外层 try/except 中记录日志后再次抛出。
- 请求/响应结构全部用 Pydantic BaseModel 声明并通过 `response_model=` 绑定到装饰器，禁止直接返回裸 dict。
- 可选或重型依赖（如 evaluation、graph_extractor、tracing）采用函数内 `import ...` 延迟导入，避免启动时强依赖导致失败。
- 前端通过 `st.markdown(..., unsafe_allow_html=True)` 内嵌 CSS 样式类名（如 `.chunk-card`、`.pipeline`、`.source-card`）配合少量 HTML 片段完成可视化渲染。
