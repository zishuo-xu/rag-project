# 分层难基准设计规格(CMRC-Hard)

> 状态:设计稿(2026-07-30)。目标:把评测从"检索饱和 1.0 的自建简单集"升级为"分层可控难度、公开可复用的基准",让检索能力有空间被展示、让所有数字不再自说自话。

## 1. 为什么要造它(诚实的动机)

现有 300 题 CMRC 集上检索命中 1.0——**这不是荣耀,是评测的失败**:题太容易,区分不出检索能力,也测不出系统的真实短板。审阅者对"自建语料上的满分"天然打折。

本基准不假装是众包新数据集(CMRC 是来源,如实标注),它的价值主张是:**可控的难度分层 + 零成本复现 + 针对 RAG 真实失败模式的定向设计**。

## 2. 五层结构(目标 ~400 题)

| 层 | 题量 | 测什么 | 构造方法(全部零 LLM,确定性) |
|---|---|---|---|
| **standard 标准层** | 100 | 回归锚点,与历史数字可比 | 从现有 300 题步长抽样 |
| **distractor 强干扰层** | 150 | 实体归属精确性(RAG 最常见失败) | 每道题的索引语料中注入 3 篇强干扰文档(见 §3) |
| **multihop 多跳层** | 50 | 跨文档组合推理 | 扩展既有 15 题:按语料共现关系确定性生成 2-hop 链式题(模板:"A 的 B 的 C") |
| **unanswerable 无答案层** | 50 | 拒答准确率(诚实度指标) | 两类:① 实体不在语料;② 实体在但所问属性不存在。期望行为=拒答,幻觉即失败 |
| **numerical 数值层** | 50 | 精确数值抽取 | 年份/数量题 + 上下文中注入相近干扰数字(如 gold=1963,干扰句含 1961/1968) |

难度分层本身就是报告素材:同一系统五层数字画一条衰减曲线,比单一 F1 信息量大一个量级。

## 3. 强干扰文档构造(distractor 层核心)

对每道题(q, gold 文档 D, 答案 a),注入三类干扰,强度递增:

1. **主题近邻干扰**:按 jieba 词汇重叠度从语料中选与 D 最相似但答案不同的 3 篇文档入索引(构建期 BM25 式打分,确定性);
2. **实体嫁接干扰**:取另一篇同类文档 D',将其主语实体替换为 q 所问实体(确定性字符串替换)——一篇"看似相关、事实归属错误"的文档,直接打实体错属失败模式;
3. **数值近邻干扰**(仅数值题):干扰文档含相近但错误的数字。

干扰文档只进 hard 索引(data/chroma_db_hard),不污染原索引;gold 答案的可答性必须保持(构建脚本自带验证:D 仍在索引中且答案句未被改动,验证失败则丢弃该题并上报)。

## 4. 指标

- 各层独立:`hit@5`、`coverage`、端到端 F1/EM;
- **干扰抵抗率** = distractor 层 hit − standard 层 hit(负值即检索在干扰下的衰减幅度,核心新指标);
- **拒答准确率** = 无答案层正确拒答比例 + 该层幻觉率(必须 ~0);
- 数值精确率 = 数值层 EM。

## 5. 与现有评测体系的关系(分层并存,不替换)

| 用途 | 数据集 | 角色 |
|---|---|---|
| 日常回归门(pre-push) | 300 题全量 + 50 题切片 | 不变,守"不退化" |
| **能力探针(新)** | CMRC-Hard 五层 | 守"有多强",发版/对外报告用 |
| 零 LLM 快检 | 检索评测 | 不变 |

关键:**hard 基准上检索 hit 预期从 1.0 降到 0.7-0.9——这是设计目标,不是事故**。数字降下来,故事才立得起来:之后的每一点提升都发生在有区分度的区间里。

## 6. 构建与复现

- `scripts/build_hard_eval.py`:确定性(固定步长/排序,无随机数),零 LLM,输入 = 现有 `data/cmrc_docs/` + `data/eval_dataset_cmrc_full.json`,输出 = `data/eval_hard.json`(五层标注 `stratum` 字段)+ `data/cmrc_docs_hard/`(含干扰文档,标注 `distractor_type`);
- `scripts/ingest_hard.py`:灌 `data/chroma_db_hard` 独立索引;
- `run_e2e_eval.py` 复用:加 `--stratum` 过滤(数据集字段已支持 `--slice` 机制,同构扩展);
- 构建产物提交入库(clone 即用,与现有复现链同等待遇)。

## 7. 诚实边界(写进未来报告的免责声明)

1. 派生基准,非独立语料来源——价值在难度分层与可复现,不在规模或原始性;
2. 实体嫁接干扰是人工痕迹较重的构造,真实场景的干扰更模糊——本基准测的是"干扰存在时的下界表现";
3. 多跳/无答案层题量各 50,单层结论标注 ±7pp 置信带;
4. 无答案层的"正确答案"定义(拒答措辞)会影响拒答准确率的绝对值,跨系统比较时用相对序而非绝对值。
