# 我回退了自己做的 Graph RAG 升级,因为 F1 是 −0.004

> 关于 RAG 特性归因的一套纪律:独立开关、干净对照、容差设计、口径一致。以及三份我如实写进报告的无效结果——它们不是这篇文章的边角料,是它的主角。因为没有它们,我所有"有效"的结论都只是自我表扬。

## 一、那个让我不安的问题

先交代出事的那一刻。

我给 RAG 系统的图谱通道做了一次结构升级:从零 LLM 的 jieba 共现图,换成 LLM 抽取的类型化三元组(人/作品/地点/机构/职位分类 + 100% 的 chunk 溯源)。从任何工程角度看这都是明确的"能力升级"——关系有了类型,每个实体都追得到来源。

代价也不含糊:全量图谱重建 3.6 小时,约 2782 次 LLM 调用。

然后我跑了 300 题评测。结果:

```
F1       −0.004  (波动带内)
检索命中  持平
延迟     +12%
```

三连跑,结论稳定:**结构能力升级了,检索收益没有兑现。**

那一刻我面前有两条路。第一条:把它包装成"结构化基础设施,为未来能力铺路",留在系统里——3.6 小时的心血,谁舍得删?第二条:承认这是一次净亏损的升级,回退,把 3.6 小时的重建成本还给每一个 clone 这个项目的人。

我选了第二条。而让我能选第二条的,不是意志力,是一套让"无效"无处藏身的归因纪律。这篇文章就讲这套纪律——以及为什么我越来越觉得,**一个没有无效结果的实验报告,不是好报告,是广告。**

## 二、为什么 RAG 的归因特别难

在讲方法之前,先承认问题的硬度。RAG 系统里"这个特性有没有用"之所以难回答,有四层噪声叠在一起:

1. **交互效应**:autocut 截断和 rerank 是耦合的,分解和路由是耦合的,单特性的贡献不是加法;
2. **LLM 非确定性**:同一份代码、同一批题,跑两次 F1 能差 0.01-0.02——你测到的"提升"可能只是这次采样手气好;
3. **数据集效应**:换一批题,结论可能整个翻转(后面会讲我差点被这个骗了);
4. **指标与目标的错位**:词法 F1 涨了,答案真的变好了吗?

多数技术博客对付这些噪声的办法是——不处理。贴一个 before/after 表格,数字涨了,特性有效,发文。读者默认作者诚实,作者默认自己没被骗。

我的办法是给实验定四条纪律,每条都对应上面一层噪声。

## 三、四条纪律

### 纪律一:独立开关 + 延迟中性的默认路径

13 项特性,每项一个布尔开关,失败自动降级回基线行为。这听起来只是"配置化",但它真正的作用是让 **"A/B 只差一个开关"在物理上成立**——没有隐式依赖随着开关一起变动,对照才是干净的。

容易忽略的是后半句:**默认路径必须延迟中性**。新特性不许往热路径加在线 LLM 调用,重活转移到索引期(上下文增强、图谱抽取都在灌库时做完),线上判断尽量复用 reranker 已有的分数。为什么这条算归因纪律?因为如果每个开关都悄悄改变延迟,那"开特性"就同时改了质量和时延两个变量——你再也说不清一次评测的变化是质量驱动还是时延驱动。变量不隔离,归因从根上就不成立。

### 纪律二:确定性抽样 + 分层,让对照可以"配对"

日常 A/B 不用全量(太贵),用 50 题快速切片。关键在抽样方式:**从 300 题里按固定步长 6 抽取,不用随机数。** 每次运行命中的是完全相同的 50 道题。

这不是为了"可复现"这种虚名,而是为了**配对比较的统计效力**:同一道题在两个版本下的 F1 之差,方差远小于两组独立样本均值之差。固定题集把"版本差异"从"题目差异"里剥了出来。分层同理:零 LLM 检索评测(秒级)→ 50 题切片(分钟级)→ 300 题全量(发版级),各层管各层的决策,不用 15 题的切片去背"总体有效"的结论——小样本只配说"方向",不配说"结论"。

### 纪律三:容差设计——承认噪声,然后管理它

LLM 非确定性是物理事实,装作它不存在的人会被它反复打脸。我的质量门(eval-as-gate)对端到端 F1 设 ±0.05 的相对容差:低于这个幅度的"退化"判通过,因为那是采样噪声,不是代码退化。

两个方向的坑都要防:**没有容差的门是误报工厂**——每次 push 都在"退化",三个月后所有人开始无视它;**没有基线的门是摆设**——退化和谁比?容差多大?都无从谈起。容差不是对质量放水,是把有限的注意力集中到真信号上。另有一条不参与容差的绝对底线:链路健康度——任何一题抛异常即 fail,因为"系统崩了"不是噪声,不接受"抖动"解释。

### 纪律四:口径一致——我最贵的教训

这条是我交学费学来的,两个学费:

**学费一,provider 口径。** 我在 deepseek 上建了基线,某天换 qwen 跑了一次,F1 差了 0.11。0.11 是什么概念?我所有特性优化加起来的增益都没有 0.11。如果把这两次跑批混在一起看趋势,归因会彻底失真——你以为看到了代码的效果,其实只是换了个模型。现在每次跑批的结果落盘时强制记录 provider,跨 provider 不做退化比对。

**学费二,数据集口径——这个差点骗过我自己。** 300 题复刷后,F1 0.600,比旧基线(n=100 精选集)的 0.691 低了 0.09。第一反应:我改坏了什么?排查半天,真相比 bug 更值得记住:同一个 300 题运行里,前 128 题均值 F1 0.735,后 172 题约 0.50——**题间难度本身就不均**,旧基线恰好抽在了简单的一半上。不是代码退步,是尺子换了。如果我没做这一步核对,会去修一个不存在的 bug;或者更糟,悄悄不提这个数字。**换集必须重定基线**,从此写进流程。

## 四、三份无效结果(本文主角)

纪律讲完,看它们逮住了什么。

### 无效结果一:Graph RAG 升级,F1 −0.004

就是开头那次。决策的完整推理是:结构升级属实,但收益测不出来(三连跑稳定在波动带内),而成本是确定的(重建 3.6h + 延迟 +12%,且每个复现者都要付重建成本——这直接顶撞"可复现"这个硬目标)。收益存疑、成本确定,回退;类型化版本保留为可选路径,报告里如实记录"关系无类型化、实体含 jieba 噪声"的现存缺陷。

这次回退让我确认了一件事:**做"回退自己功能"的决策,需要数据,不需要勇气。** 如果归因是模糊的,我会说服自己留着它;正因为 −0.004 测得干净,回退才是一个技术决策而不是情感事件。

### 无效结果二:多跳分解,收益在方差内

多跳查询分解 + 路由修复后,F1 0.276→0.289,+0.013。听起来是正的?但负对照里单样本的波动就达到 +0.275——**+0.013 完全在噪声里**。报告里我没写"F6b 有效",写的是"弱正/方向性,幅度在方差内"。

承认"我不知道它有没有用",比讲一个 +0.013 的故事难受得多。但读者不傻,面试官更不傻——一个敢写"在方差内"的作者,他说"+3.3pp"的时候你不需要打折。

### 无效结果三:生成侧 prompt,两轮阴性——然后它救了场

端到端 F1 长期卡在 0.60。诊断显示瓶颈在生成侧(检索命中率 1.0,材料都送到了),我做了两轮生成 prompt 重构。结果:两轮都没有显著提升。结论写成"生成侧残差天花板,短期无已知空间"。

但这两轮阴性做对了一件事:**排除了"措辞风格"这个假设**。后来我对 99 道低分题做失败分类,发现 93 道不是措辞问题,是"实体错属"和"问答方面错位"——问 A 的籍贯,模型答成文档里共现的 B 的信息。基于这个**被两轮阴性过滤剩下的诊断**,我只加了两条定向 prompt 原则(实体校验 + 对准所问方面),F1 0.600→0.633。

**那两轮阴性是这次成功的必要前置。** 没有它们,我会继续在措辞风格上空转。这是我第一次切身理解:阴性结果不是实验的失败,是实验在干活——它在收缩假设空间。

## 五、一个正面归因长什么样

最后看纪律用在"有效"上是什么样。7/28 的零 LLM 化(把 CRAG 分级、查询改写从 LLM 改成规则/分数),我没有改完就宣布成功,而是搭了一个受控 A/B:

同一个索引(git worktree 检出旧代码,复制同一份向量库)、同一批 60 题、同一个 deepseek,只换代码:

| 指标 | 精简前 | 精简后 | Δ |
|---|---|---|---|
| 平均延迟 | 7533ms | 3747ms | **−50%** |
| 端到端 F1 | 0.547 | 0.577 | +0.030 |
| EM | 0.083 | 0.136 | +0.052 |
| 忠实度 | 0.979 | 0.962 | −0.017 |

报告结论写得很克制:n=60 下质量读数应表述为"**无显著差异、方向全正**",而不是"质量提升";延迟 −50% 是结构性的(摘掉两次 LLM 往返),不需要谦让;忠实度 −0.017 与"无损"叙事方向相反,如实标注为待观察项。

注意这份结论的长相:它没有把所有数字都讲成好消息。**这正是它能被相信的原因。**

## 六、可以带走的东西

三句话:

1. **负面结果是正面结果的信用背书。** 一份只有好消息的报告,它的消息会自动被打折;一份敢写 −0.004 的报告,它的 +3.3pp 才值钱。这不是道德选择,是传播学。
2. **归因纪律是廉价的科学方法。** 你不需要发表论文的严谨度,但需要它的骨架:隔离变量(开关)、可配对的对照(固定题集)、承认噪声(容差)、统一量具(口径)。四条做到,你的结论就从"我觉得有效"升级成"测出来有效"。
3. **让无效无处藏身,是一种系统能力,不是一种品德。** 我没有比谁更诚实,我只是建了一套让诚实比粉饰更省事的流程——开关、门、落盘口径、报告模板。品德靠不住,流程靠得住。

回退 Graph RAG 升级那天,我在报告里写了一行字:"结构能力升级,检索收益未兑现,回退。"十几个字,没有解释,没有找补。那是我在这个项目里最得意的几行字之一。
