# 5 分钟演示脚本(面试/路演用)

> 目标:让不懂实现的人在 5 分钟内相信三件事——它真的能跑、它比一般 RAG 讲究、它的数字是测出来不是编出来的。
> 前置:服务与前端已启动,索引已制备(见 README「复现评测数字」),评测报告文件已打开备用。

## 0. 开场(15 秒)

「这是一个生产级中文 RAG 系统。它的特点不是功能多——是 13 项特性每一项都有独立开关、有 A/B 归因数据,包括几项我证明无效后如实记录的结果。」

## 1. 跑起来(45 秒)

```bash
python main.py                    # 终端 A:API :8000(已启动则跳过)
streamlit run frontend/app.py     # 终端 B:前端 :8501
```

浏览器开 `http://localhost:8501`,顺带闪一下 `http://localhost:8000/docs`(Swagger)。

 talking point:「embedding 和重排是两个本地模型,不花 API 钱、不进隐私;LLM 走 OpenAI 兼容端点,可一键换。陌生人 clone 下来唯一要填的是一个 LLM key。」

## 2. 一次问答 + 引用溯源(60 秒)

问一个语料里的事实题,例如:「范廷颂哪一年被任命为主教?」

展示顺序:
1. **流式逐字出答案**——「首字是秒出的,忠实度校验在流末跑,不阻塞你看到的任何一个字。这是投机流式:先吐后验,验不过追加更正。」
2. **答案后的引用标记**——「每个论断回溯到源块,零在线 LLM,用 claim 和 chunk 的 embedding 余弦关联。」

再问一个**语料里没有**的问题,展示诚实拒答:「材料里没有的,它说不知道,而不是编一个。」(忠实度 0.986 的直观版)

## 3. 打开引擎盖:一次请求里发生了什么(60 秒)

切到 API 日志或 `/api/metrics`,指着一次请求讲:

「一次常规问答,在线 LLM 调用只有两次——生成 + 忠实度裁判。检索五路并行召回、RRF 融合、本地重排、膝点截断 61 篇→6 篇,全部零 LLM。均延迟 4.5 秒,历史上这个数字是 42.6 秒。」

talking point(如果对方是工程师):「默认路径延迟中性是我定的红线——新特性想上线,先证明它不往热路径加 LLM 调用。」

## 4. Agentic 开关(60 秒,可选)

把配置 `use_agentic` 打开,问一个多跳题:「范廷颂担任总主教的那个教区在哪里?」

「这个问题要组合两个事实。agent 自己决定分解成子问题分别检索——手写 ReAct 状态机,零 LangGraph 依赖。关键不是它多聪明,是它知道什么时候停:证据充分度硬门控,CRAG 判充分就强制结束,finish 率从 33% 到 93%。这段故事我有完整的三轮迭代记录,包括一轮失败的。」

## 5. 数字怎么来的(75 秒)——**最重要的一段**

打开 `docs/superpowers/reports/2026-07-29-zero-llm-balance-report.md`:

1. 「300 题 CMRC 全量评测,300/300 零失败,检索命中 1.0,这是饱和。」
2. 翻到 A/B 表格:「我把一次优化做成了受控实验——同索引、同题、同模型,只换代码:延迟砍半,质量方向全正。结论我写的是'无显著差异',不是'提升'——n=60 下我要诚实。」
3. 翻到开放项:「这里有三个无效结果:Graph RAG 升级 F1 −0.004,我回退了;生成侧 prompt 两轮阴性,我登记为天花板。**一个敢写无效结果的项目,它的有效期才是真的。**」

## 6. 收尾(15 秒)

「复现链是闭环的:README 四个命令,索引制备到评测复现全程文档化,依赖由 uv.lock 锁定。我的目标从一开始就是——陌生人 clone 后能复现这里的每一个数字。谢谢。」

## 应急预案

| 状况 | 处置 |
|---|---|
| LLM 超时/限流 | 展示本地部分:检索评测 `run_retrieval_eval.py` 秒级出数,零 LLM 依赖 |
| 前端起不来 | 直接打 Swagger `/api/chat`,curl 一条流式请求,效果更"硬核" |
| 答案出错(真出了) | **不要慌,这是素材**:当场指给它看忠实度标记/引用,讲系统如何自检与纠正 |
| 时间只剩 2 分钟 | 砍掉 3、4,只做 2(问答+引用)和 5(报告)——数字比功能更能说服人 |

## 一句话备份(电梯版)

「一个中文 RAG 教学样板:检索饱和、忠实度 0.99、延迟从 42 秒压到 4.5 秒,13 项特性全部独立开关 + A/B 归因,无效结果如实留档——陌生人 clone 可复现每一个数字。」
